# 🚀 Supply Chain Dashboard | Power BI
This Repo contains my first power-bi dashboard that describes supply chain dataset.This dashboard focuses on providing meaningful insights into supply chain performance through key business metrics and interactive visualizations.

# Tools Used
- Figma
- Power BI

# 📊 Key Performance Indicators (KPIs):
• Total Revenue Generated
• Total Products Sold
• Total Stocks
• Average Shipping Costs
• Average Lead Time

# 📈 Dashboard Visualizations:
• Products Sold vs. Availability
• Products Sold & Revenue Generated by Location
• Products by Transportation Mode
• Revenue Generated by Product Type
• Product Type by Inspection Result
• Shipping Time by Product Type
• Production Volume by Product Type
• Products by Routes
